# AI Dev Best Practices

A living playbook for AI-assisted software development. Opinionated, practical, and refreshed weekly from what actually works in real projects.

## Guides

- [Building Agent Skills](docs/agent-skills.md): the SKILL.md open standard, when skills beat prompts, and how to write ones agents actually use.
- [Writing AGENTS.md](docs/agents-md.md): repo-level agent instructions, what good ones contain, and what to leave out.
- [Using MCP](docs/mcp.md): Model Context Protocol in daily dev workflows, useful servers, config patterns, and pitfalls.
- [Open Knowledge Format](docs/open-knowledge.md): the emerging spec for portable, agent-readable knowledge bundles.
- [Spring Boot](docs/spring-boot.md): AI-assisted development for Spring Boot projects, scaffolding, testing, and the JPA pitfalls agents hit.
- [React](docs/react.md): AI-assisted development for React projects, component generation, state management, and testing.
- [Generating Documentation from a Codebase](docs/codebase-documentation.md): top-down vs bottom-up strategies, chunking large repos, prompt patterns, and keeping generated docs in sync with CI.
- [Building an Application Knowledge Base](docs/knowledge-base.md): what an app knowledge base contains, bootstrapping one from code when no docs exist, and keeping it current.
- [Spring Boot API Documentation](docs/spring-boot-api-docs.md): OpenAPI standards with springdoc, annotation patterns, RFC 7807 error responses, versioning, and contract testing.
- [React Component Documentation](docs/react-component-docs.md): Storybook stories as docs, prop tables, design tokens, accessibility notes, and usage examples.
- [Application Architect Artifacts](docs/app-architect-artifacts.md): the C4 diagrams, ADRs, NFRs, integration maps, and deployment views an application architect produces.
- [Solution Architect Documentation](docs/solution-architect-docs.md): the Solution Architecture Document template, integration patterns, data flow, security views, and decision records.
- [Writing Good Acceptance Criteria](docs/acceptance-criteria.md): INVEST stories, Gherkin Given/When/Then, example mapping, and acceptance criteria anti-patterns.

## Cadence

Updated weekly, every Wednesday. Each update is logged in [docs/weekly-log.md](docs/weekly-log.md) with what changed and why.

## Contributing

This is a personal playbook, but issues and PRs with real-world corrections are welcome. If an agent burned you this week, add the gotcha.
